# Game Store HTTP images

Store preview images are not included in this repository. Configure `coinImagesURL`
to point at an HTTP host containing the catalog's `13/` category icons and `64/`
offer previews, and provision those assets using the host's existing image
deployment process.

The public Store image pack does not include previews for the six new bundles or
the Voodoo, Sighting and Cyclops Steel beds. Those nine offers have no tile
preview on any client version. The native 15.25 furniture and furniture-set
offers use item appearances and retain their previews.
