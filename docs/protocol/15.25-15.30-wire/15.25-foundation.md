# 15.25 foundation retained by 15.30

These packet families were already present by 15.25 and are still required by the 15.30 task, boss, soul-seal and spell-target UI. They are separated from the true 15.30 delta to avoid charging or implementing unchanged work twice.

## Task Board C2S `0x5F`

```text
5F action:u8 [action fields]
```

| Action | Meaning | Fields after action |
|---:|---|---|
| `0x00` | open bounty view | none |
| `0x01` | open weekly view | none |
| `0x02` | set bounty difficulty | `difficulty:u8` |
| `0x03` | reroll bounty | none |
| `0x04` | claim daily reroll | none |
| `0x05` | select bounty task | `taskIndex:u8` |
| `0x06` | claim bounty reward | none |
| `0x07` | upgrade talisman | `talismanIndex:u8` |
| `0x08` | deliver weekly task | `taskIndex:u8` |
| `0x09` | set weekly difficulty | `difficulty:u8` |
| `0x0A` | open shop | none |
| `0x0B` | buy shop offer | `offerId:u16` |
| `0x0C` | unlock preference slot | `slot:u16` |
| `0x0D` | clear preferred race | `slot:u16` |
| `0x0E` | clear unwanted race | `slot:u16` |
| `0x0F` | assign preferred race | `slot:u16, raceId:u16` |
| `0x10` | assign unwanted race | `slot:u16, raceId:u16` |

Evidence: `reference`. This table comes from the official-style Task Board module used as the 15.25 foundation.

## Task Board S2C `0x5B`

The first payload byte selects the view.

### View `0x00`: bounty

```text
5B 00
taskCount:u8
  repeat taskCount:
    taskIndex:u8
    raceId:u16
    requiredKills:u16
    experienceReward:u32
    bountyPoints:u8
    currentKills:u16
    state:u8
    taskType:u8
dailyRerolls:u8
rerollState:u8
difficulty:u8
repeat exactly 4 talisman records:
  level:u16
  canUpgrade:u8
  upgradeCost:u16
preferenceSlotCount:u8
  repeat preferenceSlotCount:
    unlocked:u8
    preferredRaceId:u16
    unwantedRaceId:u16
```

### View `0x01`: weekly

```text
5B 01
anyCreatureRequired:u16
anyCreatureCurrent:u16
killTaskCount:u8
  repeat killTaskCount:
    raceId:u16
    requiredKills:u16
    currentKills:u16
itemTaskCount:u8
  repeat itemTaskCount:
    taskIndex:u8
    itemId:u32
    requiredAmount:u32
    currentAmount:u32
    completed:u8
difficulty:u8
killExperienceReward:u32
deliveryExperienceReward:u32
killsCompleted:u8
itemsCompleted:u8
difficultySelectionAvailable:u8
suggestedDifficulty:u8
nextReset:u32
thirdSlotUnlocked:u8
taskHuntingPoints:u32
soulseals:u32
```

The `soulseals:u32` tail is present in the post-15.21/current reference. Non-empty bounty and weekly views should still be wire-tested against 15.30 before release because the available reference predates 15.30.

### View `0x02`: shop

The empty shop boundary is:

```text
5B 02 00
```

This package does not claim a new 15.30 non-empty shop-record delta. Reuse the existing 15.25 implementation or capture the server's natural shop response.

Evidence: `reference`; non-empty 15.30 views remain unverified.

## Boss difficulty S2C `0x2F`

```text
2F action:u8
if action == 0x00:
  bossRaceId:u32
  selectionEnabled:u8
  selectedDifficulty:u16
  lowestDifficulty:u16
  groupHighestDifficulty:u16
  personalHighestDifficulty:u16
  badLuckBonus:u32
  bossName:string
  difficultyLabel1:string
  difficultyLabel2:string
  difficultyLabel3:string
  difficultyLabel4:string
if action == 0x00 or action == 0x02:
  updatedSelectedDifficulty:u16
  conCount:u8
    repeat conCount: modifier:string
  proCount:u8
    repeat proCount: modifier:string
```

`action 0x01` has no fields after the action byte. The synthetic open/close fixtures have static decoder coverage but have not been accepted as live 15.30 UI proof.

Evidence: `static`, `live` still required.

## Talk `0x96`: optional spell target tail

The normal Talk payload is followed by a target mode in confirmed 15.25/15.30 builds:

```text
96
speakType:u8
if private mode: receiver:string
if channel mode: channelId:u16
text:string
targetMode:u8
if targetMode == 1 or targetMode == 2:
  targetPosition:position
```

`targetMode 0` has no position. Values greater than `2` should be rejected.

Some TibiaAPI Talk models stop after `text`; that older model is not byte-complete for this build family.

Evidence: `static/reference`, first confirmed in 15.25.

## Resource balance request/response

C2S request:

```text
ED resourceType:u8
```

S2C response:

```text
EE resourceType:u8 value:u32-or-u64
```

Use `u32` for:

- `0x1E` charm;
- `0x1F` minor charm;
- `0x20` maximum charm;
- `0x21` maximum minor charm;
- `0x3C` NPC-trade quest currency;
- `0x50` unspent skill points;
- `0x56` bounty points;
- `0x57` Soulseals.

The known 15.25 reference uses `u64` for other listed money, prey, task-hunting, forge and gem/fragment balances. Resource `0x49` was added to the 15.30 identifier table, but its official value width is not wire-confirmed; see `identifiers.md`.

## Graphical Effects `0x83`

The 15.25/current graphical-effects container is reused for the new 15.30 effect and missile IDs.

Magic effect:

```text
83 position effectCommand:u8=0x03 effectId:u16 source:u8 end:u8=0x00
```

Distance effect:

```text
83 fromPosition effectCommand:u8=0x04 effectId:u16 deltaX:i8 deltaY:i8 source:u8 end:u8=0x00
```

Known source values are `0` global, `1` own, `2` other players and `3` creatures. The new IDs are in `identifiers.md`; the container layout itself is not a 15.30 delta.
